## 辨析

主要是平凡构造函数的约束条件：

1. 是编译器**隐式生成**的，或用户显式声明为 `=default` 且未违反其他条件。
2. **没有用户提供的函数体**（即不能写 `{}` 以外的逻辑）。
3. 类**没有虚函数**（`virtual`），没有**虚基类**
4. 所有直接基类和非静态成员变量**本身都具有平凡构造函数**。（反着说就是，成员/基类是非平凡类型则是非平凡，因为会递归触发他们的非平凡构造函数，比如包含 std::vector）

平凡构造函数除了内存占位之外，没有任何特殊的语义逻辑

## 区分的意义

### 前置知识

#### `memset`、`memcpy` 和 `memmove`

[C memset、memcpy 和 memmove：记忆操作终极指南](https://learnmandu.com/blog/memc/blogs/memset-memcpy-memmove-c)

内存是连续的字节数组，每个字节都有唯一的十六进制地址。

C 语言中处理内存的三大核心函数：`memset`、`memcpy` 和 `memmove`。他们都使用 `void *`，意味着它们不关心内存里存的是什么（是整数、浮点数还是结构体），它们只把内存看作**原始字节（Raw Bytes）**。他们所有操作的计数单位 n 都是 `size_t`，代表字节数。

- `memset(void *s, int c, size_t n)` 的底层逻辑：它将地址 `s` 开始的 `n` 个字节，每一个都设为 `(unsigned char)c`。即为将某一块连续的内存区域全部设置为同一个值。

  所以如果我想让 int 数组全都赋值为 1 时，我是不能用 memset 的，因为 int 是 4 个字节，而 memset 是为每一个字节都赋值为 1，最终会变成奇怪数字。

  所以 `memset` 常用于清零
- `memcpy` 用于把一段内存的内容原封不动地复制到另一段内存。它的特点是**速度极快**，但是它假定"起点"和"终点"完全不重叠。会直接调用 CPU 的 SIMD 指令复制

  **内存重叠（Overlap）**，源内存区域（src）和目标内存区域（dest）在地址空间上有交集。

  **内存对齐**：现代 CPU 访问 4 字节或 8 字节对齐的地址比访问任意地址快得多。

  `memcpy` 会先处理掉开头的几个不对齐字节，后使用 64 位（8 字节）甚至 256 位（SIMD）指令批量搬运，最后处理末尾。

  **编译器内联**：如果你拷贝的大小 `n` 是一个常数（比如 `memcpy(d, s, 8)`），现代编译器（GCC/Clang）通常不会调用库函数，而是直接生成一条 `mov` 指令。这叫内联优化。

  同时，编译器在编译期能确定无重叠时，会将 `memset` 换成 `memcpy`
- `memmove` 会自动检查你的起点和终点有没有重叠。如果有重叠，它会换个顺序搬（比如从后往前搬或者使用临时缓冲区），保证数据不会被覆盖。
- 这三个函数都不具备**边界检查**，且不是**原子操作**，且**类型无关**

### 编译器优化与性能

**平凡类型**：可安全使用 `memcpy`/`memmove`/`memset` 进行批量拷贝或清零。数组初始化时直接按内存块操作，**零运行时开销**。

平凡类型的对象在内存中的布局是**连续**且**确定**的（**POD 布局**）。

对于平凡类型，全零的**位模式（Bit Pattern）**在逻辑上等同于该类型的初始状态。（上文提到，`memset` 最好只能赋 0，其他数字的结果不是想要的）

如果你强行对一个带有虚函数指针的对象执行 `memset(0)`，那么他的虚函数表指针也会被抹成 0。但是平凡类型里面只有数据，没有指针。就是很安全的数据清零，即初始化。

平凡类型的拷贝被称为 **按位拷贝（Bitwise Copy）**。

当你拷贝 `std::vector` 时，你不能只拷贝它的指针地址，你必须执行"深拷贝"，否则两个对象会指向同一块堆内存，导致二次释放。这需要调用"拷贝构造函数"。

但是平凡不持有外部资源的引用，它的状态完全由它拥有的那几个字节决定。平凡代表着它只代表着几个字节，里面的东西又很干净，与外界毫无关系，仿佛无限接近于字节，所以它可以安全的使用这三个函数。也无限接近上文的内存块。

最后，关于**零运行时开销**，用两个优化机制解释：

1. **跳过函数调用栈**

   编译器通过静态分析确认是平凡构造后，会略过一些函数调用和栈帧跳转

2. **内存成块**

   当你写 `int arr[100] = {0};` 时：

   - 编译器不会生成 100 条指令去一个一个改写内存。
   - 它会将其优化为一条 **`rep stos`** 指令（在 X86 架构下）或者直接调用经过高度优化的库函数 `memset`。
   - 这种操作利用了 CPU **写合并（Write Combining）和缓存行（Cache Line）**特性，一次性填充整个内存块，速度接近硬件极限。

   参考：[Write Combine 和 Cache 是什么关系](https://zhuanlan.zhihu.com/p/607637105)

3. **静态初始化与数据段**

   如果一个平凡类型的全局数组在编译时就确定了初值，编译器甚至不会在运行时产生任何代码。它会直接把这些值写入二进制文件的 `.data` 或 `.bss` 段。程序加载到内存的那一刻，数据就已经在那了。

**非平凡类型**：必须逐个对象调用构造函数，无法**向量化**或**批量优化**。创建 100 万个对象时，性能差异可达 10~100 倍。

### 类型特征与元编程

```cpp
#include <type_traits>

static_assert(std::is_trivially_default_constructible_v<int>);      // true
static_assert(std::is_trivially_constructible_v<std::string>);      // false
static_assert(!std::is_trivial_v<NonTrivialClass>);                 // true
```

广泛用于模板约束、容器优化（如 `std::vector` 的预留空间策略）、序列化框架设计。

### POD

- 平凡构造函数是 **POD（Plain Old Data）类型**的必要条件之一。
- POD 类型内存布局与 C 结构体完全一致，可直接用于：

  - 网络协议打包/解包
  - 共享内存/硬件寄存器映射
  - 跨语言 FFI 调用

POD 在 C++11 之后被分为两个正交属性：平凡和标准布局。
