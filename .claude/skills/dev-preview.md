# 开发预览工作流

对本项目的所有改动，遵循以下流程：

## 流程

1. **改代码** — 按需求修改
2. **启动预览** — 运行 `pnpm dev` 启动开发服务器
3. **展示效果** — 告知 pear 改了哪里，让 pear 在浏览器中查看效果
4. **等确认** — pear 确认没问题后再继续
5. **构建验证** — 运行 `pnpm build` 确保构建通过
6. **提交** — pear 确认后提交

## 注意事项

- 开发服务器默认在 `http://localhost:4321`
- 修改内容页面需要刷新浏览器查看
- 不要跳过预览步骤直接提交
